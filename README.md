# asset-load-test

에셋 싣기 시험 (A9 — 진짜 GitHub Pages에서 클립 라이브러리를 싣는지). 시험용 공개 정적 저장소이며, 시험이 끝나면 지울 수 있습니다.

- `clips/<지문>.mp4` — 클립 (fMP4 한 파일, H.264 + AAC). 모두 ffmpeg의 시험 신호 (`testsrc2` · `smptebars` · `sine`)로 지은 것 — 남의 저작물 없음.
- `clips.json` — 라이브러리 목록 (`asset-clips` 판 1)
- `works/<이름>/work.json` — 작품 메타데이터 (`asset-work` 판 3 — 클립을 잇는 차례 · 갈래)
